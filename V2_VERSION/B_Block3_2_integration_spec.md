# B 組｜Block 3 + Block 2 + 最終整合 — 執行規格書

> 目的：把「模型 + 經濟」收斂成**一條商業故事線**：漏斗 → 誰會復活/為什麼 → 該對誰做什麼 → 值多少錢 → NAPL/限制。
> 定位：純分析與框架，**不重訓 B0–B3 模型**。決策機率一律用 **校準後 LightGBM**、**時間外 test n=38,572**（縮放時標注假設）。
> 執行順序：**Pre-task（Block 1 一致性修正）→ Block 3（洞察）→ Block 2（分級/地圖）→ 整合（單一商業故事）**。
> 誠實邊界：所有洞察為**相關性、非因果**；三層經濟用同一套產業校準參數；treat-none = 放棄真實營收。

---

## Pre-task：Block 1 一致性修正（小修，但影響頭條，先做）

1. **單位修正（Layer 2/3，最關鍵）**：模型的 `u` 是「復活營收中屬於增量的**比例**(ratio)」；產業實證「1.2%、2.97%」是**絕對百分點(pp)**，兩者不可直接比。
   - 換算：incrementality ratio = 絕對增量 ÷ 受眾轉換率。可換算的 email 例（4.2%→5.4%）→ u ≈ (5.4−4.2)/5.4 ≈ **0.22**。
   - 把產業帶改成「換算後 u ≈ 0.15~0.25」疊上破口圖（破口 u≈0.27）。
   - **修正結論**：在實務 u≈0.2 下，全發券落在損益兩平的**微虧側**（非「虧 2~2.5M」），模型多賺約 **NT$0.7~1M** 並避開下檔風險。重算「treat-all 虧損組數」（先前 46/96 疑為把 pp 當 ratio 餵入所致）。
2. **兌換率一致性（Layer 1）**：把硬省的兌換率從 0.4 改為產業實證 **8~15%（區間呈現）**，重算毛省（預期 top-30% 縮放後約 NÚ$1M 量級）。三層自此共用同一套經濟參數。
3. 更新 `ECONOMIC_NARRATIVE.md` 對應數字與結論句；保留舊版為對照、註明修正原因。

**驗收**：三層經濟參數一致；頭條金額用修正後數字；單位換算有寫清楚。

## Block 3：洞察挖掘（目標 3–5 條可行動洞察）

**方法（每條共用）**：對候選特徵做分桶 dependence vs 校準復活率；**控制 is_imputed**（必要時控制 ShopId）；報效應量（Spearman / 復活率高低差 / 單調性）；每條寫成一句「**發現 → 所以呢 → 建議動作**」。**門檻：能講出決策相關的一句話才留，講不出行動的丟掉。** 全部標為相關性、非因果。

**候選清單（依優先序）**

1. **★ t0_discount_ratio vs 復活（頭條，且回餵 Layer 2 的 u 先驗）**
   比較「全價回購 vs 用深折扣回購」的後續復活率，控制 is_imputed。
   假說：折扣驅動的回購較不黏著 → 若成立，這是對「發券」本身的根本質疑，也是專案最有份量的發現。把結果換算成一個資料導向的 u 估計，回頭校準 Layer 2 的 u 先驗（閉環）。
2. **t0_amount vs 復活（已完成，匯入為已證實洞察）**
   Spearman ≈ −0.90，控制 is_imputed 後仍成立。直接引用，不重跑。
3. **回購通路 vs 復活（t0_channel_type / t0_channel_detail；含 POS 線下標記）**
   offline_ratio 已是 SHAP 正向強特徵。量化「線下/POS 回購 vs 線上/App 回購」的復活率差。假說：店內回購＝在地習慣黏著。
4. **沉睡深度 vs 復活（dormancy_gap_days / hist_recency_days）**
   畫復活率隨沉睡天數的衰減曲線，找有沒有「斷崖」。
5. **MemberCardLevel 復活梯度**
   找出「高到某等級復活幾近必然」的門檻 → 這群絕對別發折扣（直接餵 Block 2 高分層動作）。
6.（選配）t0 買新品類 vs 老品類；interval_cv 規律性。

**輸出**
- `output/B/B4/insights/`：每條選用洞察一張圖 + `INSIGHTS.md`（發現/所以呢/動作 三段式）。
- t0_discount_ratio 的 u 估計寫回 `ECONOMIC_NARRATIVE.md` 的 Layer 2 先驗段。

**驗收**：3–5 條，每條有圖、有效應量、有一句可執行建議；折扣那條務必跑出且閉環回 Layer 2。

## Block 2：客戶分級 + 策略地圖 + 品牌差異化部署

**目標**：把分數變成可部署的分群與行動方案，串接 Block 1 的政策與 Block 3 的洞察。

### 2A. 三層分級（沿用 Block 1 門檻）
用校準機率分高/中/低（高＝top-30% 或 P≥0.6、中、低）。每層報：人數、復活率、平均未來價值（`future_90d_revenue`）、可觸及比例（行銷開通）、**建議動作**：

| 層 | 復活機率 | 動作（接 Block 1 政策） |
|----|---------|------------------------|
| 高分 | 高（本來就會回） | **停發折扣**、改不花折扣的留存（會員/跨售）→ 省 margin |
| 中分 | 中（可被說服者） | **精準投放**留存資源（profit-max τ* 落點），券發這裡 ROI 最高 |
| 低分 | 低（多半一次就走） | 放生省觸及成本，或下重本搶救（高風險，二選一） |

### 2B. 二維策略地圖
**propensity（P 復活）× 價值（預期未來營收）** 做 2×2 或 3×3 象限，每格命名動作。重點凸顯：
- **低 P × 高價值 = 高價值流失風險** → 留存預算最該花的地方。
- 高 P × 高價值 = VIP → 保護、別打折。
（可另做一版把價值軸換成「可觸及性」，呼應 Block 1 的可觸及版 profit。）

### 2C. 品牌差異化部署（輕量，吸收已取消的 Block 4 精華）
直接用現成 `brand_heterogeneity` 數據：低復活率品牌（RZSHERLB 等，lift 4×）→ 優先導入模型精準投放、ROI 最高；高復活率品牌（3WUOySTy）→ 客人本來就會回，別過度投資 targeting、重點改成別過度打折。**誠實警示**：小樣本品牌（NOmceSRC n≈2.4K、AUC≈0.59）per-brand 不可靠 → 結論是「pooled 模型 + 用品牌決定在哪部署」，不是每品牌各訓一個。

**輸出**
- `output/B/B5/segmentation/`：`tier_table.csv`（三層指標+動作）、`strategy_map.png`（二維象限）、`brand_deployment.md`、`PLAYBOOK.md`（每層/每象限的行動方案）。

**驗收**：三層有明確動作且對齊 Block 1 政策；策略地圖象限可讀、行動具體；品牌建議有誠實小樣本警示。

## 最終整合：串成單一商業故事 ★ 報告主軸

**目標**：產出 `output/B/BUSINESS_STORY.md`（＋一張「帶價值的漏斗」總圖），把全線串成一條敘事，當報告骨架。

**故事線（依序）**
1. **問題與漏斗（B5）**：111 萬沉睡 → 21% 回流下單 → 其中 62% 一次就走。多數回流是假的。
2. **能不能即時、只用訂單資料分辨真假？（B3 模型）**：AUC 0.71、贏 RFM-logreg +15%、跨三模型家族穩健；t0 回購行為是最強訊號之一。
3. **為什麼會/不會復活？（Block 3 洞察）**：折扣驅動的回購偏空、單筆大額＝流失警訊、線下＝黏著……（每條一句行動）。
4. **那該對誰做什麼？（Block 2 分級＋地圖）**：高分停發、中段精準投放、低分放生；低 P×高價值要搶救；品牌差異化部署。
5. **值多少錢？（Block 1 修正版經濟）**：省 margin 區間 + 「實務增量下全發券近損益兩平、模型避開下檔並多賺 ~NT$0.7~1M」+ 96 組假設穩健。
6. **NAPL 收束 + 誠實限制**：靜態母體（可推廣為全動態，方法論貢獻）；無因果/uplift 資料、洞察為相關性；未來工作＝holdout 實驗 + 動態偵測。

**核心賣點一句話**：純訂單即可在回購當下分辨「真復活 vs 路過」，把被浪費的折扣 margin 省下、把留存資源精準投在可被說服的中段，且結論在合理假設範圍內穩健、不依賴券的因果。

**驗收**：BUSINESS_STORY 六段成線、數字與各 Block 一致、誠實限制完整；一張總圖能獨立講完故事。
