## 4. 經濟（**單位修正後**，post Pre-task）　〔來源：`B4/economics/pretask_consistency.json`〕

> **單位修正（最關鍵）**：模型 u 是「復活營收中屬增量的**比例 ratio**」；產業實證 1.2%/2.97% 是**絕對 pp**，不可直接比。換算 ratio：email 4.2%→5.4% → u = 1.2/5.4 = **0.22**。

| 項目 | 修正後數值 |
|------|------|
| 產業 winback uplift（**換算成比例**） | **15% ~ 25%** |
| treat-all 由負轉正破口 | **u ≈ 0.27**（0.269） |
| 實務區間 (u=0.15/0.20/0.25) treat-all 利潤 | −1.11M / −0.64M / −0.18M（**近損益兩平、微虧**；**非**舊版「虧 2~2.5M」） |
| 同上 模型 − 全發券 | +1.26M / +0.96M / +0.70M → **+0.7 ~ 1.3M** |
| Layer 1 硬省（停發 top-30%，縮放回流總體） | 兌換率 8%→**NT$0.84M**、12%→**1.25M**、15%→1.57M、40%→**4.18M** |
| Layer 1 損益兩平 uplift（top-30%） | 兌換率 8~40% → u_be 2.7% ~ 13.3% |
| Layer 3 穩健（96 組 u×毛利率×兌換率） | 模型嚴格勝 treat-all **96/96**、勝 RFM **96/96**、treat-all 虧損 **22/96**（舊 46/96 為 pp 誤餵） |
| Layer 3 模型−全發券優勢 | 平均 +256,732、最小 +3,139、最大 +1,651,615 |
| 決策經濟基準 | 毛利率 0.55、兌換率 0.40（即時觸發錨定）、固定 5；m=703.8、復活均營收 1279.6 |

> **作廢數字（勿再引用）**：舊「產業 uplift 1.2~3% 直接當 u」「treat-all 虧 2~2.5M」「treat-all 虧損 46/96」「模型勝 RFM 79/96」。

> **原版 profit（`B4/b4_eval_summary.json`，非 uplift 框架）**：τ*=0.12、模型 6.92M vs 全發券 6.82M。此為最初的「全額毛利」框架，**已被 uplift 修正版取代為主敘事**，僅作早期對照保留。
